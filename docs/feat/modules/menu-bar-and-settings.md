# General 与运行控制

用户可以在 General 查看辅助功能权限是否可用，并选择是否在登录 Mac 后自动启动；关闭设置窗口后，AutoQuit 继续在菜单栏运行。菜单栏同时提供重新打开设置、检查更新和退出入口。

## 模块概览

- **实际入口**：手动启动 AutoQuit > “General”；关闭设置窗口后：菜单栏窗口形图标 > “Preferences”、“Check for Updates…”或“Quit”。
- **可触达条件**：AutoQuit 正在运行。
- **前置条件**：查看状态、打开设置和退出不要求辅助功能权限；执行应用规则需要授权。
- **主要结果**：用户可以确认权限、发起系统授权、控制开机启动、重新打开设置、进入软件更新或停止 AutoQuit。
- **相关旅程**：[为一个应用设置自动关闭](../journeys/configure-app-auto-quit.md)、[让 AutoQuit 登录后自动运行](../journeys/start-autoquit-at-login.md)、[将 AutoQuit 更新到新版本](../journeys/update-autoquit.md)

## 用户目标

### 确认规则能否执行

用户在 General 直接看到“已授权”或“未授权”。未授权时可以点击“请求权限”，再按 macOS 提示完成设置。

完成信号：General 显示绿色的已授权状态和“可以按 APP Rules 处理应用”。

### 控制 AutoQuit 是否继续运行

用户可以关闭设置窗口并保留后台处理，也可以从菜单栏选择“Quit”停止 AutoQuit。

完成信号：关闭窗口后菜单栏图标仍在；选择“Quit”后图标消失。

### 登录后自动运行

用户可以打开“开机启动”，让 macOS 在下次登录后自动启动 AutoQuit；关闭该开关后，后续登录不再自动启动。

完成信号：开关保持开启，并在下一次登录 Mac 后自动出现菜单栏图标；设置窗口不会自动弹出。

## 流程步骤

### 主流程：完成授权

1. 启动 AutoQuit。
   - 系统反馈：显示名为“AutoQuit”的设置窗口和菜单栏图标，默认进入“General”。
   - 数据结果：读取 macOS 当前保存的授权状态。
   - 规则引用：[`GEN-R-001`](#gen-r-001)
2. 在未授权状态下点击“请求权限”。
   - 系统反馈：macOS 显示辅助功能授权提示；按钮本身不直接授予权限。
   - 数据结果：授权尚未改变。
   - 规则引用：[`GEN-R-003`](#gen-r-003)
3. 按系统入口前往“隐私与安全性 > 辅助功能”，开启 AutoQuit。
   - 系统反馈：General 自动更新为已授权状态。
   - 数据结果：授权由 macOS 保存。
   - 规则引用：[`GEN-R-002`](#gen-r-002)、[`GEN-R-003`](#gen-r-003)

完成信号：General 显示已授权，APP Rules 可以执行。

### 分支流程：关闭设置窗口

1. 关闭 AutoQuit 设置窗口。
   - 系统反馈：窗口和 Dock 中的运行入口隐藏，菜单栏图标保留。
   - 数据结果：授权与已保存规则不变，后台处理继续。
   - 规则引用：[`GEN-R-004`](#gen-r-004)
2. 需要再次设置时，点击菜单栏图标并选择“Preferences”。
   - 系统反馈：设置窗口重新出现。
   - 数据结果：不修改权限或规则。
   - 规则引用：[`GEN-R-005`](#gen-r-005)

结束状态：用户返回设置窗口。

### 分支流程：退出 AutoQuit

1. 点击菜单栏图标并选择“Quit”。
   - 系统反馈：AutoQuit 直接退出，菜单栏图标消失。
   - 数据结果：规则停止执行；权限和规则仍保留。
   - 规则引用：[`GEN-R-006`](#gen-r-006)

结束状态：再次使用需要重新启动 AutoQuit。

### 分支流程：启用或停用开机启动

1. 在 General 切换“开机启动”。
   - 系统反馈：启用成功时开关保持开启；需要 macOS 批准时，开关显示关闭，并出现说明和“打开登录项设置”；其他注册失败时，开关恢复为 macOS 当前状态。
   - 数据结果：macOS 更新 AutoQuit 的登录项状态。
   - 规则引用：[`GEN-R-007`](#gen-r-007)
2. 开关开启后，在下一次登录 Mac 时等待系统启动 AutoQuit。
   - 系统反馈：AutoQuit 显示菜单栏图标，但不自动打开设置窗口。
   - 数据结果：登录项保持开启，AutoQuit 开始按现有权限和规则运行。
   - 规则引用：[`GEN-R-009`](#gen-r-009)

结束状态：关闭开关只影响后续登录，不退出当前正在运行的 AutoQuit。

## 完整能力

### 查看和请求权限

General 持续展示辅助功能权限状态。未授权时出现“请求权限”；已授权时显示规则可以工作，不再显示请求按钮。

### 后台保留与明确退出

关闭设置窗口不停止 AutoQuit。“Quit”不经二次确认，立即停止后台检查。

菜单栏中的“Check for Updates…”进入[软件更新](software-updates.md)，不改变辅助功能权限、开机启动选择或应用规则。

### 控制开机启动

General 的“开机启动”开关反映 macOS 当前保存的登录项状态。开启后由 macOS 在用户登录时启动 AutoQuit；关闭后当前实例继续运行，但后续登录不再自动启动。系统要求批准时，General 提供前往登录项设置的入口，并在用户返回 AutoQuit 后刷新状态。

## 可用选项

### “General”

- **用户用途**：确认辅助功能权限状态。
- **选择方式**：设置窗口侧栏标签。
- **出现位置**：AutoQuit 设置窗口。
- **结果摘要**：显示授权状态，并在未授权时提供请求入口。
- **规则引用**：[`GEN-R-001`](#gen-r-001)

### “请求权限”

- **用户用途**：请求 macOS 引导用户完成辅助功能授权。
- **选择方式**：仅在未授权时出现的按钮。
- **出现位置**：General 的辅助功能权限区域。
- **结果摘要**：显示系统授权提示。
- **规则引用**：[`GEN-R-003`](#gen-r-003)

### “开机启动”

- **用户用途**：让 AutoQuit 在用户登录 Mac 后自动开始运行。
- **选择方式**：开关。
- **出现位置**：General 的开机启动区域。
- **结果摘要**：开启或关闭 macOS 保存的 AutoQuit 登录项。
- **规则引用**：[`GEN-R-007`](#gen-r-007)、[`GEN-R-009`](#gen-r-009)

### “打开登录项设置”

- **用户用途**：在 macOS 要求批准 AutoQuit 登录项时完成允许操作。
- **选择方式**：仅在需要系统批准时出现的按钮。
- **出现位置**：General 的开机启动区域。
- **结果摘要**：打开 macOS 登录项设置；用户返回 AutoQuit 后，General 刷新开关状态。
- **规则引用**：[`GEN-R-007`](#gen-r-007)

### “Preferences”、“Check for Updates…”与“Quit”

- **用户用途**：重新打开设置、检查软件更新或停止 AutoQuit。
- **选择方式**：菜单栏菜单项。
- **出现位置**：菜单栏窗口形图标展开后的菜单。
- **结果摘要**：“Preferences”打开设置；“Check for Updates…”开始检查发布版本；“Quit”立即退出。
- **规则引用**：[`GEN-R-005`](#gen-r-005)、[`UPD-R-001`](software-updates.md#upd-r-001)、[`GEN-R-006`](#gen-r-006)

## 规则

### GEN-R-001

**规则：启动时打开 General。**

- **条件**：用户手动启动 AutoQuit。
- **行为**：产品打开设置窗口，显示“General”和“APP Rules”，并创建菜单栏图标。
- **结果**：用户立即看到当前辅助功能权限状态。
- **限制或例外**：AutoQuit 的界面同时包含英文模块名和中文说明。

### GEN-R-002

**规则：权限状态自动更新。**

- **条件**：AutoQuit 正在运行，用户在 macOS 中授予或撤销辅助功能权限。
- **行为**：General 重新检查授权状态。
- **结果**：状态在“已授权”和“未授权”之间更新；未授权时规则暂停执行。
- **限制或例外**：授权开关本身只存在于 macOS 系统设置。

### GEN-R-003

**规则：请求按钮只发起系统授权。**

- **条件**：General 显示未授权，用户点击“请求权限”。
- **行为**：AutoQuit 请求 macOS 显示辅助功能授权提示。
- **结果**：用户可以按系统入口前往辅助功能设置。
- **限制或例外**：点击按钮本身不会授予权限；系统提示文案由 macOS 决定。

### GEN-R-004

**规则：关闭窗口不退出应用。**

- **条件**：用户关闭设置窗口。
- **行为**：AutoQuit 保留菜单栏运行。
- **结果**：已有规则可以继续执行。
- **限制或例外**：当前没有“关闭窗口时退出”选项。

### GEN-R-005

**规则：菜单栏恢复设置入口。**

- **条件**：AutoQuit 正在运行。
- **行为**：用户选择“Preferences”后，产品打开设置窗口并置于前台。
- **结果**：用户可以继续查看权限或编辑规则。
- **限制或例外**：菜单中的“AutoQuit”是不可选择的标题。

### GEN-R-006

**规则：Quit 立即停止 AutoQuit。**

- **条件**：用户从菜单栏选择“Quit”。
- **行为**：AutoQuit 不经确认直接退出。
- **结果**：后台规则停止执行，菜单栏图标消失。
- **限制或例外**：macOS 权限和已保存规则不会被删除。

### GEN-R-007

**规则：开机启动开关以 macOS 注册状态为准。**

- **条件**：用户在 General 切换“开机启动”，或从 macOS 登录项设置返回 AutoQuit。
- **行为**：切换开关时，AutoQuit 请求 macOS 启用或停用登录项并读取实际注册状态；从系统设置返回时，AutoQuit 重新读取状态。
- **结果**：启用成功时开关保持开启；macOS 要求用户批准时，开关显示关闭，并出现说明和“打开登录项设置”；停用成功时开关保持关闭。
- **限制或例外**：系统设置中的批准由用户完成，AutoQuit 不能代替用户开启；其他注册失败只会让开关恢复为 macOS 当前状态，当前没有错误详情。

### GEN-R-008

**removed**

- **状态**：removed
- **说明**：2026-08-09 起，登录项启动不再自动打开设置窗口；现行规则见 [`GEN-R-009`](#gen-r-009)。

### GEN-R-009

**规则：开机启动在下一次登录时后台生效。**

- **条件**：“开机启动”保持开启，用户退出登录或重新启动 Mac 后再次登录。
- **行为**：macOS 自动启动 AutoQuit。
- **结果**：AutoQuit 显示菜单栏图标，并按当前权限和已保存规则开始运行；设置窗口不自动打开。
- **限制或例外**：需要设置时，从菜单栏选择“Preferences”；关闭开关不会退出当前实例；选择“Quit”不会自动关闭已经启用的开机启动。

## 摩擦点与恢复

权限没有更新、开机启动等待系统批准、开关无法保持开启或关闭窗口后仍在运行时，按症状查看[用户摩擦点与恢复路径](../friction-points.md)。

## 业务数据

### 辅助功能授权

- **创建或更新**：用户在 macOS 中授予或撤销。
- **持久化结果**：由 macOS 保存，关闭或退出 AutoQuit 不会删除。
- **主要用途**：General 展示状态，并控制应用规则是否执行。
- **删除影响**：撤销后所有应用规则暂停。
- **完整生命周期**：[辅助功能授权数据流](../data-flows.md#accessibility-authorization)

### 开机启动选择

- **创建或更新**：用户在 General 切换“开机启动”。
- **持久化结果**：由 macOS 保存，退出 AutoQuit 后仍保留。
- **主要用途**：决定下一次登录 Mac 时是否自动启动 AutoQuit。
- **删除影响**：关闭后不再随后续登录自动启动，当前实例不受影响。
- **完整生命周期**：[开机启动选择数据流](../data-flows.md#launch-at-login-setting)
