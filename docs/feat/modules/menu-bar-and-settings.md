# 菜单栏与设置

用户可以从设置窗口请求辅助功能权限；关闭窗口后，AutoQuit 继续在菜单栏运行，直到用户选择“Quit”。

## 模块概览

- **实际入口**：启动 AutoQuit > 无标题设置窗口；关闭窗口后：菜单栏窗口形图标 > “Preferences”或“Quit”。
- **可触达条件**：AutoQuit 正在运行；设置窗口关闭后，菜单栏图标仍然存在。
- **前置条件**：macOS 26.0 或以上；打开设置和退出 AutoQuit 不要求辅助功能权限。
- **主要结果**：用户可以请求权限、重新打开设置，或停止 AutoQuit。
- **相关旅程**：[让无窗口的 Preview 自动退出](../journeys/automatically-quit-preview.md)

## 用户目标

### 请求自动退出所需权限

用户在首次使用或权限缺失时，从“General”点击“Click Me”，再按 macOS 提供的入口前往辅助功能设置。

完成信号：macOS 系统设置显示 AutoQuit 的辅助功能权限已经开启。AutoQuit 窗口本身不显示权限状态。

### 控制 AutoQuit 是否继续运行

用户可以关闭设置窗口而保留后台功能，也可以从菜单栏明确退出 AutoQuit。

完成信号：关闭设置窗口后菜单栏图标仍在；选择“Quit”后图标消失，AutoQuit 不再执行自动退出。

## 流程步骤

### 主流程：完成授权后保留后台运行

1. 启动 AutoQuit。
   - 系统反馈：出现无标题设置窗口；左侧只有“General”，内容区显示“Click Me”；菜单栏同时出现窗口形图标。
   - 数据结果：尚未改变辅助功能授权。
   - 规则引用：[`CTL-R-001`](#ctl-r-001)
2. 在“General”中点击“Click Me”。
   - 系统反馈：权限缺失时，macOS 显示辅助功能授权提示；权限已经可用时，窗口没有变化。
   - 数据结果：点击按钮本身不授予权限。
   - 规则引用：[`CTL-R-002`](#ctl-r-002)
3. 选择系统提示中前往系统设置的操作。
   - 系统反馈：macOS 打开系统设置；具体按钮文案使用系统语言。
   - 数据结果：授权仍未改变。
   - 规则引用：[`CTL-R-002`](#ctl-r-002)
4. 在“隐私与安全性 > 辅助功能”中开启 AutoQuit。
   - 系统反馈：权限状态由系统设置显示；AutoQuit 窗口不显示成功提示。
   - 数据结果：授权由 macOS 保存，供 Preview 自动退出使用。
   - 规则引用：[`CTL-R-003`](#ctl-r-003)
5. 关闭 AutoQuit 设置窗口。
   - 系统反馈：设置窗口和 AutoQuit 的 Dock 图标消失，菜单栏图标保留。
   - 数据结果：AutoQuit 继续运行；关闭窗口不撤销系统权限。
   - 规则引用：[`CTL-R-004`](#ctl-r-004)

完成信号：设置窗口已关闭，菜单栏仍有 AutoQuit 图标。

### 分支流程：拒绝或关闭系统授权提示

触发条件：辅助功能权限尚未授予，用户拒绝或关闭 macOS 提示。

1. 关闭系统提示或选择拒绝。
   - 系统反馈：提示消失，AutoQuit 设置窗口没有状态变化。
   - 数据结果：权限保持未授予；自动退出不能工作。
   - 规则引用：[`CTL-R-002`](#ctl-r-002)
2. 需要恢复时，直接打开 macOS“系统设置 > 隐私与安全性 > 辅助功能”。
   - 系统反馈：系统设置显示 AutoQuit 的权限开关。
   - 数据结果：授权尚未改变。
   - 规则引用：[`CTL-R-003`](#ctl-r-003)
3. 开启 AutoQuit 的辅助功能权限。
   - 系统反馈：系统设置显示权限已开启；AutoQuit 窗口没有成功提示。
   - 数据结果：macOS 保存授权。
   - 规则引用：[`CTL-R-003`](#ctl-r-003)

结束状态：权限开启后可以进入 Preview 自动退出主流程；未开启时该分支结束。

### 分支流程：权限已经可用

触发条件：用户已经为 AutoQuit 开启辅助功能权限。

1. 再次点击“Click Me”。
   - 系统反馈：AutoQuit 设置窗口没有可见变化。
   - 数据结果：已有权限保持不变。
   - 规则引用：[`CTL-R-002`](#ctl-r-002)

结束状态：无需再次授权，可以直接使用 Preview 自动退出。

### 分支流程：重新打开设置

触发条件：设置窗口已经关闭，AutoQuit 仍在菜单栏运行。

1. 点击菜单栏中的窗口形图标。
   - 系统反馈：显示含“Preferences”和“Quit”的 AutoQuit 菜单。
   - 数据结果：运行状态不变。
   - 规则引用：[`CTL-R-005`](#ctl-r-005)
2. 选择“Preferences”。
   - 系统反馈：无标题设置窗口重新出现并置于前台。
   - 数据结果：不会改变权限或自动退出状态。
   - 规则引用：[`CTL-R-005`](#ctl-r-005)

结束状态：返回“General”。

### 分支流程：退出 AutoQuit

触发条件：AutoQuit 正在运行，用户要停止自动退出。

1. 点击菜单栏中的窗口形图标。
   - 系统反馈：显示 AutoQuit 菜单。
   - 数据结果：自动退出仍在运行。
   - 规则引用：[`CTL-R-005`](#ctl-r-005)
2. 选择“Quit”。
   - 系统反馈：AutoQuit 直接退出，菜单栏图标消失；没有二次确认。
   - 数据结果：自动退出和当前观察停止；macOS 中已有的权限不由此撤销。
   - 规则引用：[`CTL-R-006`](#ctl-r-006)

结束状态：再次使用需要重新启动 AutoQuit。

## 完整能力

### 打开权限请求

从启动时出现的设置窗口，或“菜单栏窗口形图标 > Preferences”，进入“General”并点击“Click Me”。AutoQuit 只请求 macOS 处理辅助功能授权，不在自身窗口内授予、撤销或显示权限。

### 后台保留

关闭最后一个设置窗口不会结束 AutoQuit。产品转为菜单栏运行，继续使用已经满足的权限和运行条件。

### 明确退出

“菜单栏窗口形图标 > Quit”结束 AutoQuit。当前没有暂停开关；需要停止自动退出时，退出整个应用是唯一入口。

## 可用选项

### “General”

- **用户用途**：进入当前唯一的设置区域。
- **选择方式**：设置窗口左侧单选标签。
- **出现位置**：AutoQuit 设置窗口。
- **结果摘要**：显示“Click Me”权限请求按钮。
- **规则引用**：[`CTL-R-001`](#ctl-r-001)

### “Click Me”

- **用户用途**：请求 macOS 处理辅助功能授权。
- **选择方式**：按钮。
- **出现位置**：“General”内容区。
- **结果摘要**：权限缺失时请求系统提示；权限已经可用时没有可见变化。
- **规则引用**：[`CTL-R-002`](#ctl-r-002)

### “Preferences”

- **用户用途**：重新打开设置窗口。
- **选择方式**：菜单项。
- **出现位置**：菜单栏窗口形图标展开后的菜单。
- **结果摘要**：把设置窗口带到前台。
- **规则引用**：[`CTL-R-005`](#ctl-r-005)

### “Quit”

- **用户用途**：停止 AutoQuit 和自动退出行为。
- **选择方式**：菜单项；菜单显示快捷键 ⌘Q。
- **出现位置**：菜单栏窗口形图标展开后的菜单。
- **结果摘要**：无确认地退出 AutoQuit。
- **规则引用**：[`CTL-R-006`](#ctl-r-006)

## 规则

### CTL-R-001

**规则：启动入口。**

- **条件**：用户启动 AutoQuit。
- **行为**：产品打开无标题设置窗口，并在菜单栏创建窗口形图标。
- **结果**：设置窗口只显示“General”和“Click Me”。
- **限制或例外**：当前没有其他设置标签或设置项，AutoQuit 自身界面为英文。

### CTL-R-002

**规则：Click Me 只发起系统权限请求。**

- **条件**：用户在“General”点击“Click Me”。
- **行为**：AutoQuit 让 macOS 检查辅助功能权限，并在尚未授权时请求系统提示。
- **结果**：权限缺失时由 macOS 提供前往系统设置或拒绝的操作；权限已经可用时，AutoQuit 窗口没有变化。
- **限制或例外**：点击按钮本身不会授予权限；系统提示文案由 macOS 决定。

### CTL-R-003

**规则：授权由 macOS 管理。**

- **条件**：用户在 macOS 辅助功能设置中开启 AutoQuit。
- **行为**：macOS 保存授权，AutoQuit 检测到权限后开始读取应用状态。
- **结果**：Preview 可以进入自动退出判断。
- **限制或例外**：AutoQuit 内没有授权开关；撤销或恢复权限都需要回到系统设置。

### CTL-R-004

**规则：关闭窗口不退出应用。**

- **条件**：用户关闭最后一个设置窗口。
- **行为**：AutoQuit 隐藏前台窗口并保留菜单栏运行。
- **结果**：菜单栏图标仍可用，自动退出不因窗口关闭而停止。
- **限制或例外**：当前没有“关闭窗口时退出”的选项。

### CTL-R-005

**规则：菜单栏恢复设置入口。**

- **条件**：AutoQuit 正在运行。
- **行为**：点击窗口形图标后显示不可选择的“AutoQuit”标题、“Preferences”和“Quit”；选择“Preferences”重新打开设置。
- **结果**：用户返回“General”。
- **限制或例外**：“AutoQuit”是菜单标题，不是可用选项。

### CTL-R-006

**规则：Quit 立即停止 AutoQuit。**

- **条件**：用户从菜单栏菜单选择“Quit”。
- **行为**：AutoQuit 不经确认直接退出。
- **结果**：菜单栏图标消失，自动退出和应用状态读取停止。
- **限制或例外**：退出 AutoQuit 不撤销 macOS 辅助功能权限。

## 替代路径与状态

关闭设置窗口后，可以从菜单栏重新打开设置，不需要重启。权限缺失时，直接从 macOS 系统设置恢复；AutoQuit 没有权限状态提示。

## 摩擦点与恢复

“Click Me”没有用途说明，设置窗口也不显示权限结果。按当前可见症状查看[用户摩擦点与恢复路径](../friction-points.md)。

## 业务数据

### 辅助功能授权

- **创建或更新**：用户在 macOS 系统设置中授予或撤销。
- **持久化结果**：授权由 macOS 保存，关闭设置窗口不会改变它。
- **主要用途**：允许 AutoQuit 读取 Preview 的前台和窗口状态。
- **删除影响**：撤销后，AutoQuit 不会请求 Preview 退出。
- **完整生命周期**：[辅助功能授权数据流](../data-flows.md#accessibility-authorization)
