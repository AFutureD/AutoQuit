# 将 AutoQuit 更新到新版本

最短路径：菜单栏窗口形图标 > “Check for Updates…” > 安装更新 > 重新打开 AutoQuit。

## 用户目标

- **触发场景**：用户想确认是否有修复或新功能可以安装。
- **想改变的状态**：当前运行的是旧版本，或用户不确定是否已是最新。
- **预期结果**：确认当前已是最新，或安全安装新版本并继续使用原有设置。

## 前置条件

- **入口出现条件**：AutoQuit 正在运行并显示菜单栏图标。
- **继续操作条件**：首个正式版本已成功发布，Mac 可以访问 GitHub Releases；安装包及更新信息通过签名验证，AutoQuit 位于可更新的位置。部分 Mac 会要求管理员授权。
- **不满足时**：更新检查或安装停止，当前版本继续运行。

## 实际入口

- **主入口**：菜单栏窗口形图标 > “Check for Updates…”。
- **到达状态**：更新窗口开始读取发布信息，当前安装尚未改变。
- **规则引用**：[`UPD-R-001`](../modules/software-updates.md#upd-r-001)

## 主路径

1. **开始检查**：选择“Check for Updates…”。
   - **系统反馈**：显示检查进度。
   - **数据变化**：读取软件更新信息，不修改当前安装。
   - **规则引用**：[`UPD-R-001`](../modules/software-updates.md#upd-r-001)
2. **确认更新**：发现新版后，在更新窗口继续下载和安装。
   - **系统反馈**：显示版本信息和更新进度；部分 Mac 会要求输入管理员用户名和密码。
   - **数据变化**：下载并验证更新包；验证完成前保留当前版本。
   - **规则引用**：[`UPD-R-002`](../modules/software-updates.md#upd-r-002)、[`UPD-R-003`](../modules/software-updates.md#upd-r-003)
3. **使用新版本**：按更新窗口提示重新打开 AutoQuit。
   - **系统反馈**：新版本启动，菜单栏图标重新出现。
   - **数据变化**：应用版本更新；原有权限、开机启动选择和应用规则继续保留。
   - **规则引用**：[`UPD-R-003`](../modules/software-updates.md#upd-r-003)

## 分支和失败路径

### 当前已是最新

- **触发条件**：发布源没有更高的构建版本。
- **用户看到**：更新窗口说明当前已是最新。
- **可执行动作**：关闭更新窗口，继续使用 AutoQuit。
- **持久化影响**：当前安装和用户设置不变。
- **结束状态**：旅程以“已确认最新”结束。
- **规则引用**：[`UPD-R-002`](../modules/software-updates.md#upd-r-002)

### 检查、授权或安装失败

- **触发条件**：网络或更新源不可用，更新信息和安装包未通过检查，用户没有完成管理员授权，或 AutoQuit 位于不可写、只读或临时打开位置。
- **用户看到**：通常会看到检查、授权或安装未完成；只读或临时安装位置等场景可能没有错误提示，AutoQuit 仍运行当前版本。
- **可执行动作**：关闭可见提示；确认 AutoQuit 位于“应用程序”文件夹；网络或发布源恢复后重新检查，并在系统请求时完成管理员授权。
- **持久化影响**：当前版本、权限、开机启动选择和应用规则不变。
- **结束状态**：重试成功后返回主路径；持续失败时当前没有备用更新入口。
- **规则引用**：[`UPD-R-004`](../modules/software-updates.md#upd-r-004)

### 用户暂不安装

- **触发条件**：发现新版后，用户关闭更新窗口或不继续安装。
- **用户看到**：AutoQuit 继续运行当前版本。
- **可执行动作**：以后再次选择“Check for Updates…”。
- **持久化影响**：当前安装和用户设置不变。
- **结束状态**：本次旅程结束，更新仍可在之后重新开始。
- **规则引用**：[`UPD-R-001`](../modules/software-updates.md#upd-r-001)

## 持久化结果

- **成功后**：AutoQuit 应用版本被替换；原有辅助功能授权、开机启动选择和应用规则继续保留。
- **取消或失败后**：当前版本和用户设置不变。
- **后续消费者**：菜单栏、General 和 APP Rules 在重新打开后继续使用原有状态。
- **数据流**：[软件更新信息](../data-flows.md#software-update-information)

## 用户可见的完成状态

- **完成信号**：更新后 AutoQuit 重新打开并显示菜单栏入口；再次检查时不再把同一构建版本列为新版。
- **尚未完成的区别**：只下载或只完成验证时，当前运行版本尚未替换；关闭更新窗口也不代表安装完成。

## 下一目标

更新完成后，在 [General 与运行控制](../modules/menu-bar-and-settings.md)确认 AutoQuit 正在按原有权限和开机启动选择运行。
