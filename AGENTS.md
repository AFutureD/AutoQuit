# Instructions

## 0x00. Importance

All changes generated by Large Language Models (LLMs) MUST be reviewed and approved by a **human** before being committed. 
The commit message MUST include an explicit confirmation of this review.

Example:
```text
**Add Documents**

This commit generated by AI. All changes authored by me.

Codex with GPT-5.5
Prompt:
Your job is trying to add documents in this swift package project.
- You should use Apple DocC format;
- You should add README.md;
- You should add doc for every swift file in @/Sources  ;
```

## 0x01. Product Document

- Any change that adds, removes, or changes user-visible behavior must update [产品功能与用户旅程文档](./docs/feat) in the same change.
- Use `$write-user-docs` skill.
- Keep the document concise and user-facing. Avoid implementation details and do not duplicate exhaustive setup or reference material from `README.md`.
